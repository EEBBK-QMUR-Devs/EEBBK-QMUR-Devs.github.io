为 EEBBK 设备
续上主线内核的生命

EEBBK-QMUR-Devs 是一群折腾底层移植的开发者： 把 Linux mainline、U-Boot、UEFI 搬到步步高系设备上， 让老硬件跑上新内核、新引导、新可能。

进入组织 看看在做什么
What we do

Linux Mainline

把 sdm660 / sm7150 等平台往主线内核搬，少补丁、多上游。

U-Boot / Bootloader

为设备维护 U-Boot 分支，打通启动链与设备树。

UEFI · Project Mu

基于 Project Silicium / Aloha 做 ARM64 UEFI 适配。

Android Device Trees

LineageOS 设备树、vendor blob、Android kernel。
